# 나의 건강 기록 (exercise_mng)

아침 운동 실적, 소모 칼로리, 체중·혈압 트렌드를 관리하는 PWA 앱입니다.
서버 없이 브라우저(localStorage)에만 저장되며 오프라인에서도 동작합니다.

## 주요 기능

- **운동 기록**: 자주 하는 4가지 운동은 전용 입력 화면 제공 (지난번 기록 값 자동 채움)
  - 🏃 런닝머신(유산소): 속도(km/h)·거리(km) → 시간 자동 계산, 속도별 MET 적용
  - 🧘 윗몸 일으키기(복부): 세트별 횟수
  - 🏋️ 벤치프레스(가슴) / 💪 덤벨(팔): 세트별 무게(kg) × 횟수, 총 볼륨 표시
  - 그 외 운동(걷기·자전거 등)은 시간·강도 기반으로 입력
  - 소모 칼로리 자동 계산: `MET × 체중(kg) × 운동시간(h)` (강도: 가볍게 ×0.8 / 보통 ×1.0 / 힘들게 ×1.25)
  - 체중은 운동한 날짜 기준 가장 최근 체중 기록을 사용 (없으면 설정의 기본 체중)
  - 스마트워치 값 등으로 칼로리 직접 입력 가능
  - 12시 이전 운동은 "아침 운동"으로 표시, 홈에 아침 운동 연속 일수(🔥) 표시
  - 일별/주별/월별 소모 칼로리 차트, 하루 칼로리 목표
- **체중**: 체중·체지방률 입력, 기간별 트렌드 차트 + 7일 이동평균, 목표 체중, BMI(대한비만학회 기준)
- **혈압**: 수축기/이완기/맥박/측정 팔, 대한고혈압학회 기준 분류, 트렌드 차트, 기간·아침·저녁 평균
- **백업** (골프 앱과 동일한 JSON 백업 방식)
  - 설정 → "백업 파일 저장"으로 `health-log-backup-YYYY-MM-DD.json` 저장
  - 모바일에서는 "공유로 보내기"로 파일 앱/iCloud/Google 드라이브에 바로 저장 가능
  - 백업 알림 주기(변경 시마다/매일/3일/매주/2주/매월) 설정 → 주기가 지나면 홈에 "백업이 필요해요" 배너 표시
  - "백업 불러오기": 합치기(중복 건너뜀) 또는 덮어쓰기
  - CSV 내보내기(엑셀용)

## 실행 / 배포

정적 파일만으로 구성되어 있어 아무 정적 호스팅에 올리면 됩니다.

- 로컬: `python3 -m http.server 8000` 후 `http://localhost:8000`
- GitHub Pages: 저장소 Settings → Pages → 브랜치 선택 후 배포된 주소를 휴대폰에서 열고 "홈 화면에 추가"

앱 파일을 수정한 뒤에는 `service-worker.js`의 `CACHE_NAME` 버전을 올려야 설치된 앱이 새 버전을 받습니다.
